# Team Project

Tai dviejų žmonių mokomasis GitHub projektas.

## Ką daro projektas

Projektas turi:
- paprastą HTML puslapį;
- CSS stilių;
- JavaScript funkciją;
- mygtuką, kuris parodo atsitiktinę rekomendaciją.

## Kaip paleisti projektą

1. Atlik Clone iš GitHub.
2. Atidaryk projekto aplanką su VS Code.
3. Surask failą `index.html`.
4. Atidaryk `index.html` naršyklėje.

## Pagrindiniai failai

- `index.html` – pagrindinis puslapis;
- `style.css` – puslapio stilius;
- `script.js` – JavaScript funkcijos.
